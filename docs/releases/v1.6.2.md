# Grindset v1.6.2

## Easier rules

- **One word:** it's always a "rule" now. "Activity" only means your screen-time page.
- **Apps by name:** the rule editor shows each app once, with its icon and what it covers ("Android app · youtube.com"). No more `android:` or `web:` identifiers. To add a website, type `example.com`.
- **Three plain choices** under **Block it**: *While I'm focusing*, *After a daily limit* (15 min, 30 min, 1 hr or Custom) and *At set times*.
- **Live summary:** a sentence under the choices says exactly what will happen, for example "YouTube is blocked while you focus and after 30 min a day." If nothing would be blocked, it says so.
- **Rule cards** say what each rule does ("Blocked while you focus"), with the daily limit bar underneath.
- Picking an app from the list adds all of it (its apps and websites) in one tap.

## Fixed

- Unticking every weekday in a schedule no longer breaks the editor.

No data, permission or sync changes from v1.6.1. Existing rules open in the new editor unchanged.

## Verification

All 152 Flutter tests pass, including the rule editor flows (presets, typed websites and app IDs with mixed capitalization, custom limits, schedules, Windows app discovery and browsing, keyboard open on a phone). The editor was checked in 390 px phone screenshots with every section open.
