# Grindset v1.6.10

## A calm minute before you lock in

- Tapping **Lock in** starts a minute of guided breathing: in for 4 seconds, out for 6. The focus session starts when it ends. **Start now** skips it, **Cancel** goes back. Nothing is blocked during the minute, and it keeps going if you switch tabs.

## Light mode on the Focus page

- The Focus page now follows **Settings → Appearance**, like the rest of the app.

## Websites on Windows without the extension

- When the Grindset extension isn't running in a browser, Grindset reads which site is open from the address bar (Chrome, Edge, Brave, Firefox, Zen). Time on each site counts toward its limits, and a blocked site's tab is closed with a notification. Only the site name is read, never the full address.
- In strict mode, a browser is only blocked as a whole when Grindset can't tell which site it's on.
- The extension still works best: it shows a block page in the tab and knows when a video is playing.

Your rules, data and permissions stay as they are.
