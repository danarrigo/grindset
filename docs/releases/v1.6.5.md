# Grindset v1.6.5

## Breaks are one tap

- When a focus session finishes, the main button offers **Start break**. When a break finishes, it offers **Lock in**. Nothing starts on its own.
- Ending a focus session early offers focus again, since stopping is not finishing. "Focus done" only shows when the timer ran out.
- Focus and break lengths are still remembered separately.

## Also

- Focus profile messages say "rule" instead of "activity".
- Groundwork for a Google Play edition with optional instant blocking. The website APK does not include it and is unchanged in what it asks for.

No data, permission or sync changes from v1.6.4.

## Verification

All 158 Flutter tests pass (three full runs in a row), including the new focus-to-break and break-to-focus flows. The website APK was checked to contain no accessibility service. A flaky storage test (secure reset of a real database file running past 30 s on a busy machine) was given more time.
