# Grindset v1.2.0

## In-app update checks

After installing this version manually once, open **Settings > App updates > Check for updates**. Newer releases show their notes and a **Download update** button for Windows x64 or Android ARM64.

Downloads open in your browser. Run the installer or approve the APK update over your existing release to preserve data. Nothing is silently installed. The app uses a public update feed and download repository without embedding GitHub credentials; app source remains private.

## Email confirmation

A public Grindset confirmation page replaces an unavailable browser page once the Supabase Auth Site URL is configured to it. Signup and the new **Resend confirmation email** action explicitly request this destination. The page distinguishes successful, expired/failed and direct visits, removes callback parameters and tells you to return to Grindset Settings to sign in. It does not store browser sessions or sign you in automatically.

Hosted configuration must point to `https://danarrigo.github.io/grindset-releases/confirmed/`. If the project still uses localhost, it must be changed in Supabase Auth URL Configuration; client code alone cannot override an unapproved redirect destination.

## Limitations

Personal-use preview, not store-reviewed distribution. Windows installers are unsigned; do not disable security protections. Do not uninstall a personal Android installation to bypass a signing conflict without preserving its data. Physical Android reliability and visible Windows completion notifications remain unverified. Normal Windows sign-in startup and several installed recovery/accounting paths still need native acceptance. Background enforcement remains voluntary and can be interrupted by the OS.
