# Grindset v1.1.0

## Ready-made starter activities

Open **Rules**, choose Instagram, YouTube, TikTok, Reddit, X, Facebook, Snapchat, Twitch or Discord, then review and save. No package-name research or manual source entry needed.

- Website hosts and Android packages are already linked, including common short links, both X domains and the two main TikTok packages.
- Suggested defaults: **30 minutes per day** and **Block during focus**. Edit the limits, sources and switches before saving.
- Existing rules are preserved. Overlapping starters are hidden to avoid suggesting duplicate restrictions.
- Known identifiers are also available in the custom editor with readable app names.
- Nothing is added automatically; selecting or cancelling a suggestion does not enable tracking, grant permissions or change cloud rules.
- Rule-editor actions and mobile navigation now accommodate large text on short screens.

See [starter details and coverage](../rule-presets.md).

## Downloads and updates

- Windows x64 installer: `grindset-1.1.0-windows-x64-setup.exe`.
- Windows portable: `grindset-1.1.0-windows-x64-portable.zip`. Extract the complete folder and run `lockin.exe`, the preserved legacy executable name.
- Android ARM64: `grindset-1.1.0-android-arm64.apk`, signed with the retained owner key.
- Chrome/Edge: `grindset-1.1.0-browser-extension.zip`. Extract and load the folder through the browser's Extensions developer mode, then pair in Grindset Settings.
- `SHA256SUMS.txt` and `android-signing-certificate.txt` accompany the downloads.

Install over the stable-key v1.0.0 release to retain data. Do not uninstall a personal Android installation to bypass a debug/release signature mismatch without preserving its data. Existing app IDs, storage, authentication and signing identity are unchanged.

## Known limitations

This remains a personal-use release, not store-reviewed distribution or physical-device certification. Windows installers are unsigned; do not disable security protections to run them. Physical Android reliability and visible Windows completion notifications remain unverified. Normal Windows sign-in startup has not completed Defender-enabled native acceptance; an older preview was quarantined during startup registration. If security software blocks the app, stop rather than bypass protection.

The email-confirmation redirect can still end on unavailable localhost after successful confirmation; return to Grindset and sign in. Website blocking requires the connected Windows extension. Native Edge accounting, some recovery/onboarding boundaries and Android post-reset redownload remain unverified. The [README](../../README.md) and platform evidence documents retain the full limitations.
