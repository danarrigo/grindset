# Grindset v1.5.0

## Tracking health

**Settings > Tracking health** distinguishes tracking-off, missing permissions/services, recent collector checks and browser-bridge contact. Windows reports foreground-monitor registration and the last confirmed native restriction presentation in this launch. Android reports Accessibility connection separately from Usage Access. Check now and setup actions reuse the existing permission/pairing flows. Configuration is never presented as proof of universal blocking or notification delivery.

## Focus profiles

Create Work, Study, Sleep or a custom profile from **Rules > Focus profiles** (Profiles on narrow screens), or the focus menu. Select saved activities and save without activating. **Use [profile]** requires confirmation before replacing this device's manual-focus flags. Budgets, schedules, source identifiers, timer deadlines and five-minute exceptions remain unchanged. Profiles are device-local; deleting a profile leaves the current selection in place. Manual changes are labeled Custom rather than pretending a profile still matches.

## Weekly recorded insights

**Activity > Weekly insights** shows seven local calendar days of this device's confirmed usage, daily trends, top app/site observations and comparisons with current activity definitions. Overall totals merge overlaps. Missing days are Not recorded, not inferred zeroes; no productivity/attention scores are invented. Budget excess is shown per activity using this device's observations and today's limits, not as a historical audit or a claim that other devices did not use the shared budget. The view refreshes every minute while open.
