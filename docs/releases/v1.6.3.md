# Grindset v1.6.3

## Find apps by name

- **Search by name:** type "Google", "ig", "twitter" or "netflix" in the rule editor. A built-in list of about 150 popular services fills in their websites, Android apps and Windows apps. It works offline.
- **Whole companies:** **All of Google**, **Microsoft**, **Meta** and **Amazon** add every service in one tap. Expand one to untick parts.
- **Your apps first:** with an empty search, the editor lists apps this device has used, then popular services and companies.
- **Websites:** type `example.com` and press Enter. No separate box.
- **Icons:** installed apps show their real icon, now on Windows too. Everything else shows a letter tile instead of a grey placeholder. Rule cards use any installed app in the rule for their icon. No icons are fetched from the internet.
- Apps outside the list show their installed name instead of an internal ID.

## Good to know

Website rules include sub-sites, so with all of Google chosen, unticking Gmail still leaves `mail.google.com` blocked in the browser (the Gmail app is unblocked).

No data, permission or sync changes from v1.6.2. Existing rules are unchanged.

## Verification

All 158 Flutter tests pass, including catalog checks (unique names, valid identifiers, each identifier owned by one service, offline search by name, nickname and website) and the editor flows (choosing all of Google and unticking Gmail, typed websites and case-sensitive Android IDs via Enter, Windows app discovery and browsing). The editor was checked in 390 px phone screenshots. The Windows icon lookup compiled in CI; it has not yet been tried on a real PC.
