# Grindset v1.6.15

## Faster on Windows

- Grindset no longer keeps a processor core busy. Checking rules against the day's activity redid the same work thousands of times a second, which made the app and the PC feel slow, more so later in the day.

## Groups in the first-run setup

- Setup now offers whole groups (Social media, Video and streaming, Games, Shopping) next to single apps. A group shares one daily limit between its apps.
- Picking a group marks its apps as included, so Instagram doesn't end up in two rules by accident.

## Fixes

- During a break, the Focus page says "on a break" instead of counting blocked rules.

Your rules, data and permissions stay as they are.

## Publication

Published 2026-11-26 as `v1.6.15` on `danarrigo/grindset-releases` from source `35d2b43`, signed run `45784160901` (all jobs passed). The speed fix came from a Windows install of 1.6.13 using a full processor core (96% over 30 seconds, about 37% on average over 3.7 hours) with steady memory; against a copy of that install's database (2,307 records that day, 15 rules), the browser extension's site list went from 390 ms to 10 ms per request in a test build. On the Android emulator, a fresh install of the run's x64 debug build showed the Groups row in setup; picking Instagram, YouTube and then Social media marked Instagram and the other social apps as included, and setup created exactly two rules, Social media and YouTube. The website APK (versionName 1.6.15, versionCode 2148) keeps the release certificate and contains no accessibility service. The Play bundle (`app.grindset`) is signed with the same certificate. All five public assets were downloaded back and matched `SHA256SUMS.txt` before `latest.json` was switched to 1.6.15.
