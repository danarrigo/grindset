# Grindset v1.4.0

## Scheduled focus hours

- **Rules > Schedule focus hours** creates an editable recurring restriction without starting a timer. Choose apps, weekdays and times before saving; tracking stays opt-in.
- Add separate time windows for split work periods or weekends. Overnight windows are supported, and the account timezone is shown in the editor and saved-rule summaries.
- Editing an activity preserves all existing schedule windows rather than retaining only the first. Existing budgets, activity identities and local focus-block choices stay intact.

## Better Windows app selection

- **Find apps on this PC** lists running windows and apps registered with Windows, with readable names and running indicators.
- Search or filter Windows, website and Android sources. **Browse for .exe** adds another local executable without launching it.
- Executable identifiers containing spaces are supported. Names/identifiers are saved, not installation paths or window titles. Windows recovery/system hosts and Grindset itself are excluded.
- App scanning runs off the UI thread. Failed scans and canceled file dialogs preserve existing selections.

## Verification

All five CI jobs passed. All 124 Flutter tests passed (one credential-dependent live test skipped); analysis and extension/site tests passed. A real isolated Windows preview discovered a running test app through the picker and enforced its saved scheduled hours with no timer running. Existing-rule preservation, multiple windows, timezone/overnight behavior and browse/cancel/error paths are covered by tests.

This is not a complete installed-package inventory. Some elevated, launcher, Store and shared-host/PWA apps may need a running-app identifier or website rule. Schedules require Grindset/tracking and the platform's blocking integration to remain available; they are not tamper-proof OS policies. No physical Android reliability claim is added.
