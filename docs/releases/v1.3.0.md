# Grindset v1.3.0

## Desktop workspace

- Windows opens at 1120×720 with persistent navigation, not a phone-sized window.
- Ctrl+1 through Ctrl+5 switch Focus, Activity, Rules, Devices and Settings without stopping a timer.
- Rules and Settings use multiple columns when space permits. Focus keeps its minimal dark timer canvas; desktop timer options use an anchored menu rather than a phone action sheet.
- Rule editing has app/source search and selected sources first. Saving a rule returns to the saved-rules section.

## Windows app rules and All social media

- Discord includes Windows Stable, PTB and Canary executables, not just its website and Android app. Telegram, Signal and WhatsApp also include distinct Windows app identifiers.
- **All social media** creates one editable combined rule across 17 supported social/messaging/video activities. It is not a claim to cover every site or unofficial client.
- Existing rules are preserved. For an older Discord rule, choose **Add desktop coverage**, review the new selections and save. Its limit, schedules and local focus setting stay intact.
- Suggested defaults remain 30 minutes per day and focus blocking. Existing individual rules still apply. Nothing is added automatically, and tracking/permissions remain opt-in.
- Returning to a blocked Windows app after an observed foreground transition shows the interruption again instead of suppressing it after the first warning. Windows executable identifiers match case-insensitively.

Windows enforcement is a foreground interruption, not a process lock or tamper-proof barrier. Websites still need the paired browser extension. Android still needs its separate Accessibility permission. Focus blocklists are local to each device.

## Updating

Use **Settings > App updates > Check for updates**, or download the Windows installer/Android ARM64 APK from this release. Install over your existing release to preserve data. Older builds without the updater need a manual installation once. Android retains the same package/signing key; do not uninstall to bypass a debug/release signing conflict without exporting first.

The portable Windows archive and browser extension must be fully extracted. The preserved Windows executable name is `lockin.exe`. Checksums and the public Android signing certificate report accompany the downloads.

## Existing limitations

Personal-use preview, not store-reviewed distribution or physical-device certification. Windows installers are unsigned; do not disable security protections. Physical Android reliability, visible Windows completion notification delivery and several installed recovery/accounting boundaries remain unverified. OS restrictions, permissions and force-stop can interrupt operation. The email-confirmation redirect now points to the public Grindset page; sign in inside the app after confirming.
