# Grindset v1.6.12

## Onboarding

- On first launch, a few short steps walk you through Grindset: what it does, which apps and sites to limit (with a daily limit), the permissions rules need, and optional extras: Focus hours, the browser extension on Windows, and signing in to sync. Every step can be skipped.
- If you already use Grindset, nothing changes: onboarding only appears on a fresh install.

## Fixes

- Windows: Grindset now adds itself back to Windows startup each time it opens while tracking is on. Before, the startup entry could be lost (for example after reinstalling), and Grindset would not start until opened by hand.
- Windows: the browser extension pairing message no longer refers to developer mode.

Your rules, data and permissions stay as they are.
