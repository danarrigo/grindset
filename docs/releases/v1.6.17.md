# Grindset v1.6.17

## Sync fixes

- Windows: sync no longer stops with "violates check constraint usage_source_identifier". Updating Grindset made Windows run its installer as a `.tmp` program, which the server refuses, and that blocked all other activity from uploading. Such entries now stay on this device and everything else syncs.
- Signing in on a device that already has rules no longer duplicates them. Rules for apps the account already limits are dropped in favour of the account's, and rules for anything new are added.
- After that first sign-in, the account's Focus hours, time zone and strict mode win without a "Saved offline edits" notice. Real saved edits are now named for what they changed (Focus hours, Strict mode) instead of always "Account timezone".

Your rules, data and permissions stay as they are. Rules already duplicated before this update stay until you delete the extra one in Rules.
