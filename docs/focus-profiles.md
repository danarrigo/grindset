# Focus profiles

Open **Rules > Focus profiles** (Profiles on a narrow screen), or **Focus menu > Focus profiles**. Profiles select whole activities: create individual app activities or smaller groups first if you need different per-app selections instead of the entire All social media group. Work, Study and Sleep are suggested names, not automatically enabled policies. Create an activity first, select which saved activities belong in a profile and save. Saving/editing a profile does not apply it.

**Use [profile]** asks for explicit confirmation and replaces only this device's **Block during focus** flags. It applies now, including an existing manual focus session. It does not start/stop a timer, change its deadline/duration, alter sources, override daily budgets/schedules or remove five-minute exceptions. A subsequent focus timer records the selected profile's name as its label. Existing session labels remain unchanged.

Definitions and selected-profile metadata are device-local, like existing manual-focus flags; they do not sync to other devices. Shared budgets/schedules keep their existing sync behavior. If manual edits make the focus flags differ from the selected profile, the UI says **Custom**. Deleted activities must be removed from a profile before applying it. Deleting a profile leaves the current flags in place, rather than silently unblocking apps.

Profile definitions and selected-profile metadata are included in an owner-requested local export and removed by device reset. No new permissions, cloud entity types or enforcement services are introduced.
